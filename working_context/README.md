# working-context/ — Mutable Working Context

Current beliefs, derived from the ledger: interpretation, objective, known facts, assumptions, unknowns, candidate actions.

Can be revised. Never treated as a substitute for the ledger when auditing — always trace a claim back to the ledger entry that grounds it.

Every claim carries an epistemic tag: [F] fact, [I] inference, [A] assumption, [U] uncertain, [Q] open question. Never silently promote [I]/[A] to [F].
